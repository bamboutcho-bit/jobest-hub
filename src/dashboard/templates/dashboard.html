🔑 Free Gmail SMTP Guide in 60 Seconds:
1. Open your Google Account (myaccount.google.com) → Security.
2. Ensure 2-Step Verification is ON.
3. In the search box, type "App Passwords" (or scroll to 2-Step Verification → App Passwords).
4. Name it "AutoHunt" and click Create.
5. Copy the generated 16-letter code (e.g. abcd efgh ijkl mnop) and paste it into the password box above!
